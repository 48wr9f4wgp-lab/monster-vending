# MONSTER VENDING — Vertical Slice Flow v1.0.2

Canonical basis: Vertical Slice Final Spec v1.0 + patches v1.0.1/v1.0.2.

## Primary flow
Launch → HOME → VEND → Machine reaction → Capsule anticipation → Reveal → New / Duplicate branch → Habitat ownership update → Next VEND.

## New branch
Reveal → Collection registration → Reputation gain → Monster joins Habitat → Passive income increases → Machine XP gain → Next CTA.

## Duplicate branch
Reveal → Species DNA +1 → Growth auto-applies when threshold is met → visible ★ growth required in presentation → Discovery Gauge progresses → Next CTA.

## Progression
### Machine
Machine XP threshold reached → `UPGRADE READY` → player taps explicit Upgrade → physical Machine change → Lv2 unlocks Vending Dial.

### Habitat
Reputation reaches 45 → player may expand → capacity 4 → 8 → physical Habitat growth.
